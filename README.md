# DRILL09 — 소년 이동과 방향 전환

Python과 pico2d로 구현한 1280 × 1024 방향키 이동 예제입니다.
개발 요구사항과 커밋 규칙은 [PRD.md](PRD.md)에 정리되어 있습니다.

## 실행

Python과 pico2d가 설치된 환경에서 다음 명령을 실행합니다.

```powershell
python drill09_submission.py
```

`animation_sheet.png`와 `TUK_GROUND.png`는 Python 파일과 같은 폴더에 있어야 합니다.
제출용 구현은 `drill09_submission.py`이며, `character_runs_esc.py`는 수정 전 원본 예제로 보존합니다.
이미지는 코드 파일 위치를 기준으로 읽으므로 다른 작업 폴더에서 절대 경로로 실행해도 됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 방향키 | 상하좌우 이동 |
| 가로·세로 방향키 동시 입력 | 대각선 이동 |
| 방향키 해제 | 마지막 방향으로 대기 애니메이션 |
| 반대 방향키 동시 입력 | 해당 축 이동 상쇄 |
| ESC 또는 창 닫기 | 종료 |

위아래 이동은 마지막 좌우 방향을 유지합니다. 대각선 전체 속도는 단일 방향과 같습니다.
이동량은 루프당 5픽셀이며 기존 루프 지연 0.01초를 유지합니다.
캐릭터 전체가 화면 안에 머무르며, 경계에서 완전히 막히면 대기합니다.
창 포커스를 잃으면 눌린 키 상태를 초기화합니다. 창으로 돌아온 뒤 방향키를 다시 누르세요.

## 검증

```powershell
python -m unittest -v test_character_runs_esc
python smoke_test.py
```

첫 명령은 창 없이 동작 규칙을 검증합니다. 두 번째 명령은 실제 창을 두 번 잠깐 열고,
SDL 이벤트를 주입하여 렌더링과 입력 및 두 종료 경로를 검증한 뒤 자동으로 닫습니다.
스모크 테스트는 다른 창의 간섭을 피하려고 포커스 판정만 고정합니다.
실제 키보드 조작과 창 전환 감각은 직접 실행하여 확인할 수 있습니다.
